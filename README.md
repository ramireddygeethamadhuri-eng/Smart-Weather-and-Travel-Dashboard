1. Objectives:

1.To develop a real-time weather dashboard that provides weather information for any searched city.

2.To retrieve accurate weather data using the Open-Meteo API.

3.To display current weather conditions, including temperature, humidity, wind speed, pressure, and feels-like temperature.

4.To provide a 5-day weather forecast for the selected location.

5.To provide smart travel recommendations based on weather conditions.

6.To allow users to search for cities and quickly access weather information for popular cities.

7.To provide a responsive and user-friendly interface that works on both desktop and mobile devices.

8.To demonstrate the practical use of HTML, CSS, JavaScript, APIs, asynchronous programming, and DOM manipulation.
